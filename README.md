# Hybrid Chatbot

A simple chatbot that combines **rule-based responses** and **document-based retrieval**.

## Features
- Answers FAQs using predefined rules.
- Extracts information from PDF documents.
- Easy to extend with more rules or documents.

## Usage
1. Clone the repo:
   ```bash
   git clone https://github.com/MadhuriGhadge/hybrid_chatbot.git
   cd hybrid_chatbot
   ```
### Install requirements:
pip install -r requirements.txt

### Run the chatbot:
python chatbot.py
